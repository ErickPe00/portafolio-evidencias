# Portafolio de evidencias — Desarrollo de Software

Portafolio personal responsive realizado con HTML, CSS y JavaScript. Incluye perfil, estudios, tecnologías, bases de datos, tres proyectos y contacto.

## Antes de entregar
1. Abre `config.js` con Bloc de notas o VS Code.
2. Completa `institucion`, `correo`, `github` y los 3 enlaces dentro de `proyectos`.
3. Copia tu fotografía en `assets` con nombre `mi-foto.jpg` y reemplaza `fotografia` por `assets/mi-foto.jpg`.
4. Revisa si tus tecnologías y la descripción de cada proyecto representan tu trabajo real.
5. Abre `index.html` con doble clic para comprobar el diseño.

## Publicar en GitHub Pages (sin instalar programas)
1. En GitHub, haz clic en **New repository**. Nombre recomendado: `portafolio-evidencias`. Selecciona **Public** y crea el repositorio.
2. Dentro del repositorio elige **Add file → Upload files** y sube `index.html`, `styles.css`, `script.js`, `config.js`, `README.md` y la carpeta `assets` (arrastrando los elementos de la carpeta descomprimida).
3. Pulsa **Commit changes**.
4. Ve a **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**; en **Branch** escoge `main` y `/(root)`, y pulsa **Save**.
5. Cuando GitHub indique que está publicado, visita `https://TU-USUARIO.github.io/portafolio-evidencias/`.

**Importante:** si aún no has subido los proyectos a GitHub, crea repositorios independientes y comparte sus URL. No presentes enlaces inventados como evidencia.
